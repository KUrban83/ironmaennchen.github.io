Sie leitet direkt weiter auf [ironman-planner.html](ironman-planner.html).

## Lokal testen

Einfach [index.html](index.html) im Browser oeffnen.

## Deployment mit GitHub Pages

1. Aenderungen committen und auf `main` pushen.
2. In den Repository-Settings `Pages` oeffnen.
3. `Source: Deploy from a branch`, `Branch: main`, `Folder: /(root)` waehlen.
4. Nach dem Build ist die Seite ueber die GitHub-Pages-URL erreichbar.
